# Travel Life logo — "Plan → Pin" (C1b-2)

A dotted T bar (the plan) becomes a solid L path (the trip) that ends in a map pin (where you've been).

## Colors (from frontend/tailwind.config.js)
- Compass Gold `#D97706` — mark on light backgrounds, app icon tile
- Dark-mode gold `#FBBF24` — mark and "Life" on dark backgrounds
- Charcoal `#1C1917` — pin, "Travel" on light
- Amber 700 `#B45309` — "Life" on light (readable on white)
- Cream `#F8FAFC` — reversed text / pin on dark

## Type
Crimson Pro (the app's display font): "Travel" SemiBold 600, "Life" Italic 400. Text is outlined in the SVGs, so no font is needed.

## Files
- `travel-life-logo-horizontal*.svg` — full logo (light, on-dark, mono black, mono white)
- `travel-life-mark*.svg` — symbol only
- `travel-life-app-icon.svg` — 1024 app icon (rounded gold tile)
- `png/` — app icon at 1024/512/192/180/32, mark and horizontal logo PNGs (transparent)
